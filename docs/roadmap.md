## 产品目标与范围

用户在桌面 UI 中搜索、阅读历史对话，选择启动配置和工作目录，点击后在独立终端中执行已有命令，并自动恢复所选会话。关闭 UI 不影响已打开的终端。

“Agent 选择”指选择启动入口，例如 `codex1`、`codex2`、`codexds`、`claude`，以及用户自己的命令或脚本。模型默认沿用对应命令的现有配置。第一阶段围绕查看、配置和启动展开，不要求在 UI 内实现聊天或工具执行。

代码、通用模板和文档继续在同一仓库中管理。账号配置、认证文件、历史数据库、会话、回收站和备份存放在仓库外。

## 当前基础

已有 Tkinter 桌面 UI、历史搜索与来源筛选、命令预览、独立终端启动、批量删除和 30 天回收站。

同连接 Codex 恢复和跨连接原生导入复用现有启动器；Codex 转 Claude 使用文字与工具摘要导入。Claude 转 Codex 的显式原生导入、UI 接续和隔离 resume 验证已完成。启动配置可通过界面表单或配置文件／CLI 管理；首次配置向导可选择历史来源。跨平台接续自动准备目标，明确相关的平台版本归为同一条逻辑对话，返回平台时携带所选分支新增内容。

现有使用方式见 [README](../README.md)，转换边界见 [Codex 原生导入](native-import.md) 和 [Claude 导入](claude-import.md)。
