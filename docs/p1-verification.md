## 使用边界

便携交付为源码 ZIP，需要兼容 Python／Tk，安装入口指向解压后的源码；没有内置解释器的单文件 EXE。窗口中的工具展开状态按原记录身份在本次 UI 生命周期内保留，未新增工具复制按钮。

重命名作用于本工具中的逻辑对话，数据库 v3 增加独立名称表，不写 Codex／Claude 原生标题。工具输出全文读取与历史全文索引不同：索引继续保留工具摘要，未承诺检索被截断部分；完整内容可在详情内查看。全局只命中名称、目录或 ID 时不虚构正文位置。

Linux 实测范围为上述 WSLg／xterm／Codex 组合。Claude 实际 CLI 登录／交互续聊、其他终端和原生 Wayland 桌面、真实 systemd timer 调度尚未实测；CI 仅新增定义，未推送运行。配置级隔离演练已完成，完整干净 Windows／Linux 系统装机、正式许可证和公开发布仍由 OSS 待办负责。详见 [Linux 范围](linux.md)。

更新代码后重开 UI；长期运行的历史 MCP 进程也需要重启以加载新实现。已有个人快捷入口继续使用，通用安装可用 --shared-root 指向现有配置。
